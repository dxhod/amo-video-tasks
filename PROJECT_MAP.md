# AMO Video Tasks

Мета: командний Kanban і однодоріжковий відеоредактор з незалежними версіями.

- `apps/web`: Next.js UI, Supabase SSR Auth, авторизований API.
- `apps/worker`: черга pgmq, FFmpeg/ffprobe, доставка Telegram.
- `packages/shared`: контракти, операції таймлайна, перевірки.
- `supabase`: локальна конфігурація, міграції, політики доступу.
- `tests`: інтеграційні та браузерні сценарії.
- `docs`: рішення, перевірки, журнал часу, передача до деплою.

Правила: один незмінний вихідний файл після аналізу; рендер фіксує знімок ревізії
й залишає задачу «У роботі». Виконавець явно передає обрану готову версію на review. БД відповідає
за атомарність, права, ревізії та fencing спроб worker. Файли зберігаються
в приватному Supabase Storage, локальні файли worker тимчасові.

Версії редагуються у «У роботі», крім активного рендера цієї версії. Review/done
блокують монтаж. Jobs/renders мають version_revision, історичні MP4 зберігаються.
